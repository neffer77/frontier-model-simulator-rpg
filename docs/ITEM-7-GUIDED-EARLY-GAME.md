# Item 7 — Guided Early-Game Progression

The first play session is now a seven-chapter campaign instead of an immediate full-company dashboard dump.

1. **First Call** — choose an affordable first training experiment.
2. **Training** — advance the first run and learn the core loop.
3. **First Failure** — a deterministic first-run gradient incident guarantees a teachable debugging moment rather than relying entirely on RNG.
4. **Recovery** — solve the incident, finish the repaired run, and preserve the lesson.
5. **First Model** — inspect the shipped model in Model Lab before expanding organizational scope.
6. **Build the Lab** — unlock Hiring + Org and close the first deliberate specialist hire.
7. **Company Bet** — choose a research-velocity, reliability-first, or market-pressure bias, then unlock the full management simulator.

## Unlock philosophy
Advanced systems remain present in the navigation so players understand the company will grow into them, but they display as locked and cannot be entered until the campaign reaches the appropriate chapter. Locks are enforced at the underlying legacy open functions as well as the responsive navigation, so old home-screen launchers cannot bypass progression.

Existing saves infer their campaign chapter from actual model/run/hiring state rather than being reset. A save that already has a shipped model enters the model-review/hiring portion of the campaign; completing the company-priority choice graduates the save into the unrestricted simulator.

## QA expectations
- Founder story remains first, then the Chapter 1 objective becomes active.
- Team and Model navigation begin locked.
- Data + Evals is available as an early supporting system.
- The first run receives one guaranteed `nan` incident after it has made meaningful progress if no incident has already been recorded.
- Solving that incident moves the campaign to recovery; later incidents retain normal simulation randomness.
- Shipping a model unlocks Model Lab before Hiring.
- Opening the shipped model records the model-review milestone and unlocks Hiring.
- Closing the first accepted hire advances to the company tradeoff.
- Selecting a company priority unlocks all advanced systems.
- Browser and Scriptable expose identical progression rules.
