# P5.2.9 — Native FrontierOS Projects

Projects is now a first-class FrontierOS application over the existing Phase 4D portfolio, critical-path, and program-management simulations.

## Native views
- Portfolio — active/delivered projects, schedule forecast, risk, and project creation
- Staffing — engineer allocation, workload, over-allocation, and rebalance actions
- Critical Path — blockers, dependencies, coordination overhead, and milestones
- Programs — launch trains, readiness, scope/schedule recovery, and launch actions
- History — portfolio/program event history

## Ownership
`projects` now launches through `projects.open`. Legacy `portfolioOpen`, `criticalPathOpen`, and `programOpen` mechanics remain authoritative simulation owners and are not duplicated.

## Navigation
Deep links include `frontieros://projects/project/<id>/critical` and `frontieros://projects/train/<id>`.

## QA
The focused Projects evidence workflow validates real phone and desktop shell ownership, project creation/staffing, dependency blocking, launch-train integration, deep-link routing, telemetry, screenshots, and zero page errors.
